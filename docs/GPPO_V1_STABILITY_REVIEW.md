# GPPO-v1 稳定性复核

日期：2026-08-01

## 最终判断

GPPO-v1 在 `100 updates x 16 episodes`、五个训练种子下通过本轮稳定性复核，可以进入 PCRL 改造，但结论是“工程研究基线条件性通过”，不是论文数值级或最终发表级基线。

通过依据：

- 增加四倍 rollout 预算后，GPPO 相对 PPO 的 makespan 优势仍稳定出现在 4/5 个规模；
- 五个规模的优势方向与此前 `50x8` 结果完全一致；
- GPPO validation makespan 已进入平台区，晚期继续训练没有显著改善；
- event 模式 invalid actions 没有持续恶化；
- GPPO 相对 greedy 在 3/5 个规模均值更好，但 `2x8` 仍显著更差，负结果完整保留。

因此后续可以冻结本轮 GPPO-v1 checkpoint 和协议，开始 PCRL 的向量奖励与 preference-conditioned policy 改造。PCRL 结果必须继续同时对照本轮 GPPO-v1，不能覆盖或重新调节该基线。

## 实验协议

- 固定模型容量：`6 UAV / 36 tasks`；
- 轮换训练规模：`3x12`、`4x20`、`5x28`；
- 训练预算：每种子 100 updates，每 update 16 episodes，共 1,600 rollout episodes；
- 训练种子：`1..5`；
- GPPO：`graph_mode=staged`、`sync_mode=event`；
- PPO：`graph_mode=none`、`sync_mode=none`；
- 两者共享环境、makespan 奖励、模型容量、优化器、PPO 超参数和训练预算；
- 每 10 updates 做一次固定验证，每个训练规模 20 episodes，即每点 60 episodes；
- 最终 checkpoint 是 100-update 预算内的 validation-selected best，不一定是 update 100；
- 最终评测规模：`2x8`、`3x12`、`4x20`、`5x28`、`6x36`；
- 每规模固定使用 seeds `50000..50099` 的 100 episodes。

GPPO best updates 为 `[100, 50, 80, 40, 60]`，中位数 60；PPO 为 `[10, 80, 90, 100, 80]`，中位数 80。

## 收敛诊断

收敛判断主要使用固定 validation 曲线。rollout 曲线混合三个轮换规模，并且 16 不能被 3 整除，因此只作为辅助证据。

预先使用的 GPPO 平台判据：

1. validation makespan 在 updates `50,60,70` 与 `80,90,100` 间相对变化不超过 2%；
2. updates `60..100` 斜率的 95% CI 包含 0，或绝对变化不超过 1% / 10 updates；
3. late completion rate 不低于 0.99，且窗口变化不超过 1 个百分点；
4. invalid actions 只有在斜率显著为正且晚期均值比中段高 5% 以上时才判定持续恶化。

实际结果：

| 诊断量 | GPPO 结果 | 判断 |
| --- | ---: | --- |
| validation makespan late-middle | `-0.051 +/- 0.178` | 无显著继续改善 |
| relative late-middle | `-0.49% +/- 1.77%` | 小于 2% |
| makespan slope / 10 updates | `-0.159% +/- 0.509%` | CI 包含 0 |
| completion rate middle / late | `1.000 / 1.000` | 稳定 |
| invalid late-middle | `-0.419 +/- 1.031` | 未恶化 |
| invalid slope / update | `-0.011 +/- 0.039` | 不显著为正 |
| rollout makespan `81..100 - 61..80` | `-0.043 +/- 0.460` | 辅助支持平台 |

GPPO 通过平台和 invalid-action 两项判据。一个种子的 best update 为 100，说明不能声称所有种子都已严格收敛；但五种子聚合没有继续改善信号，满足“基本收敛”的本轮标准。

## 与随机和贪心比较

GPPO 相对 random 的 makespan 在 `3x12`、`4x20`、`5x28`、`6x36` 更低，`2x8` 更高。

GPPO 相对 greedy：

| 规模 | makespan delta +/- CI | 结论 |
| --- | ---: | --- |
| `2x8` | `+0.171 +/- 0.056` | 显著更差 |
| `3x12` | `+0.035 +/- 0.118` | 均值更差，CI 包含 0 |
| `4x20` | `-0.411 +/- 0.151` | 显著更好 |
| `5x28` | `-0.206 +/- 0.263` | 均值更好，CI 包含 0 |
| `6x36` | `-0.293 +/- 0.245` | 显著更好 |

增加预算后 GPPO 已在 greedy 对比中取得 3/5 个规模的均值优势，但小规模负结果仍存在。

## 仍需保留的限制

- 原论文未公开环境和代码，本结果仍是结构级复现；
- 训练 seed 序列存在跨 run 重叠，五个 run 的环境样本并非完全独立；
- GPPO staged/event 与 PPO none/none 是“图结构 + 同步机制”的复合对照，不能单独归因；
- validation 曲线聚合三个训练规模，不能恢复每个规模的独立收敛曲线；
- actor loss 不是充分的收敛证据，当前脚本未记录 KL、clip fraction、value loss 和 gradient norm；
- validation-selected checkpoint 与 update 100 final policy 不等价。

这些限制不阻止进入 PCRL 工程改造，但在最终论文实验前需要增加非重叠训练场景和单因素消融。
